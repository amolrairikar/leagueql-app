# navigation-sidebar Specification

## MODIFIED Requirements

### Requirement: Navigate to all analytics pages
The sidebar SHALL link to all eleven analytics pages and route to them correctly, with a header
wordmark linking home and a theme toggle present.

#### Scenario: Navigation
- **WHEN** the user opens the sidebar
- **THEN** it links to My Team, Home, Standings, Matchups, Playoff Bracket, Manager Comparison,
  Manager History, Draft Recap, Draft Grades, Player Records, and Matchup Records, each routing
  correctly, with the header wordmark linking home and the theme toggle present
